# დავით კაპანაძე — აკადემიური პორტფოლიო

დავით კაპანაძის ოფიციალური აკადემიური ვებპორტფოლიოს პირველი, სრულად ქართული ვერსია. საიტი აერთიანებს კვლევით მიმართულებებს, ნაშრომების გადასამოწმებელ ბიბლიოგრაფიას, მათემატიკის სწავლების ხედვას, ინტერაქტიულ დემოს და აკადემიურ საკონტაქტო ინფორმაციას.

კანონიკური დომენია [dkapanadze.ge](https://dkapanadze.ge).

## ტექნოლოგიური სტეკი

- Next.js 16, App Router და TypeScript
- Tailwind CSS 4 და CSS variables-ზე აგებული დიზაინ-სისტემა
- Framer Motion — ზომიერი, `prefers-reduced-motion`-თან თავსებადი ანიმაციები
- KaTeX — სემანტიკურად და ვიზუალურად გამართული ფორმულები
- Lucide React — ინტერფეისის ხატულები
- BPG Banner Caps Alpha და ArchyEDT — ლოკალურად ჩატვირთული ქართული body/interface და display შრიფტები
- Noto Serif Georgian Variable — ქართული serif fallback
- STIX Two Text Variable — ინგლისური აკადემიური სათაურები და ბიბლიოგრაფია
- Resend — server-side საკონტაქტო წერილები
- Vinext/Vite ადაპტერი არსებული Sites გარემოსთან თავსებადობისთვის

## ლოკალური გაშვება

მოთხოვნები:

- Node.js 22.13 ან ახალი
- npm

```bash
npm install
npm run dev
```

შემდეგ გახსენით ტერმინალში ნაჩვენები ლოკალური მისამართი.

## შემოწმება და production build

```bash
npm run lint
npm run typecheck
npm run build
```

production ვერსიის ლოკალურად გასაშვებად:

```bash
npm run start
```

## ბიოგრაფიის რედაქტირება

ძირითადი ბიოგრაფიული ტექსტი ინახება `src/content/site-content.ts` ფაილის `aboutContent` ობიექტში. დადასტურებული აკადემიური კავშირები, ელფოსტა, ORCID და სახელი ინახება `src/config/site.ts` ფაილში.

არ დაამატოთ დაუდასტურებელი ხარისხი, თანამდებობა, თარიღი, ჯილდო ან დაწესებულება.

## ნაშრომის დამატება

ახალი ჩანაწერი დაამატეთ `src/data/publications.ts` ფაილის `publications` მასივში. ყველა ჩანაწერს სჭირდება:

- უნიკალური Latin `slug`
- ინგლისური და ქართული სათაური
- ავტორი `Davit Kapanadze`
- წელი, ტიპი, ნეიტრალური სტატუსი და კატეგორია
- მხოლოდ დადასტურებული ანოტაცია, ფორმულები და საკვანძო სიტყვები
- `externalUrl` მხოლოდ რეალური წყაროს არსებობისას
- `pdfPath` მხოლოდ რეალური საჯარო PDF-ის არსებობისას

დინამიკური დეტალის გვერდი ავტომატურად იქმნება `/publications/[slug]` მისამართზე და ემატება sitemap-ში.

## PDF ფაილების დამატება

1. ფაილს მიანიჭეთ უსაფრთხო, Latin სიმბოლოებით შედგენილი სახელი.
2. განათავსეთ `public/research/` საქაღალდეში.
3. შეამოწმეთ, რომ ფაილი რეალურად იხსნება.
4. შესაბამის ჩანაწერში დაამატეთ `pdfPath: "/research/file-name.pdf"`.

არ შექმნათ ცარიელი ან ყალბი PDF ფაილები და არ დაამატოთ ჩამოტვირთვის ბმული ფაილის არსებობის შემოწმების გარეშე.

## პროფილის ფოტო

დადასტურებული პორტრეტი ინახება `public/images/davit-kapanadze.jpg` მისამართზე და გამოიყენება `next/image`-ით hero-ში, პროფილის გვერდსა და საკონტაქტო ბარათში. გამოსახულების გზა, ზომა და ქართული `alt` ცენტრალიზებულია `src/config/site.ts`-ში. ორიგინალი არ არის დესტრუქციულად დამუშავებული; კადრირება სრულდება CSS `object-fit`/`object-position` წესებით.

## დომენისა და metadata-ს შეცვლა

დომენი, სახელები, აღწერა, ელფოსტა, პროფილები, საკვანძო სიტყვები და გარე პლატფორმის მისამართი ინახება ერთ ადგილას: `src/config/site.ts`.

გვერდის უნიკალური metadata იქმნება `src/lib/metadata.ts` დამხმარე ფუნქციით. ახალი გვერდის დამატებისას აუცილებლად განსაზღვრეთ უნიკალური სათაური, აღწერა და კანონიკური გზა.

## საკონტაქტო ფორმა

ფორმა აგზავნის წერილს `src/app/api/contact/route.ts` Route Handler-ით. საჭიროა Resend-ის server-side კონფიგურაცია; გასაღების გარეშე ინტერფეისი წარმატებას არ აჩვენებს და mailto fallback-ს სთავაზობს.

სრული გამართვის ინსტრუქცია: [CONTACT_FORM_SETUP.md](./CONTACT_FORM_SETUP.md).

საჭირო environment variables:

```env
RESEND_API_KEY=
CONTACT_TO_EMAIL=d.kapanadze@seu.edu.ge
CONTACT_FROM_EMAIL=website@dkapanadze.ge
```
